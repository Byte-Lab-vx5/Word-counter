# Word Counter

A simple word counter application built in C.

## Features

- Counts words in text.
- Simple command-line program.

## Requirements

- A C compiler, such as GCC.

## Compile

```bash
gcc word_counter.c -o word_counter
```

## Run

```bash
./word_counter
```
